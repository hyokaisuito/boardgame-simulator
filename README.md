# 🎲 ボードゲーム工房（boardgame-simulator）

ブラウザだけでボードゲームを仮想的に作り、保存し、テストプレイできるWebアプリです。
部品（コンポーネント）を並べ、ルールを **ノーコード**（プルダウンの組み合わせ）で設定できます。

## 起動方法

```bash
npm install
npm run dev      # http://localhost:5173 で開発サーバー
npm run build    # dist/ に静的ファイルを出力（任意の静的ホスティングに置けます）
npm test         # ルールエンジンのテスト
```

サーバーは不要です。`dist/` をそのまま静的ホスティングに置けば動きます。

## GitHub Pages で公開

`.github/workflows/deploy-pages.yml` により、`main`（および開発ブランチ）へ push するとテスト・ビルドのうえ自動で GitHub Pages に公開されます。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. push するか、**Actions → Deploy to GitHub Pages → Run workflow** で手動実行
3. 公開URL：`https://<ユーザー名>.github.io/boardgame-simulator/`

画面遷移は `#/edit/...` のようなハッシュ形式なので、サブパスでもページ再読み込みで壊れません。

## できること

### 1. 部品を並べる（テーブル）

| 分類 | 部品 |
| --- | --- |
| ボード | 自由ボード（画像貼り付け）、正方形マス（チェス・将棋）、六角グリッド、交点ボード（囲碁）、すごろくトラック（蛇行）、周回トラック（モノポリー型） |
| カード | 山札（空／トランプ54枚／数字カード）、単体カード、捨て札置き場、場札エリア、プレイヤーエリア（非公開設定可） |
| 駒 | ミープル、ポーン、チェッカー、リバーシ石（両面）、碁石、キューブ、チェス駒（記号）、将棋駒（裏返すと成り駒）、車、家、図形（三角・星・六角・ハート…） |
| タイル・トークン | 正方形／六角タイル（両面）、コイン、チップ、マーカー |
| ランダマイザー | D4・D6・D8・D10・D12・D20、面を自由に決めるカスタムダイス、コイントス、ルーレット、袋（ランダムに取り出す） |
| 情報・操作 | カウンター、タイマー、テキスト、ボタン（押すとルールを発動）、自由配置エリア |

- 色・文字・画像（URL またはアップロード）・サイズ・回転・所有者・グループ・自由プロパティを右パネルで設定
- カードは1枚ずつ、または `文字,枚数,色,キー=値;キー=値` 形式の一括入力で追加
- ボードのマス数・マス名・マス色・吸着（スナップ）を設定可能
- 元に戻す／やり直し（Ctrl+Z / Ctrl+Y）、複製（Ctrl+D）、削除（Delete）、矢印キーで微調整

### 2. ルールを設定する（ノーコード）

ルールは「**いつ** → **もし** → **したら**」の3段で組み立てます。

- **いつ（きっかけ）**：ゲーム開始／手番の開始・終了／フェーズ開始／ボタンが押された／ダイスを振った／カードを引いた／ボード・エリアに置かれた（マス番号つき）／裏返した／カウンター・変数が変化した／タイマー切れ／常時チェック
- **もし（条件）**：出目・マス番号・変数・カウンター・置き場の枚数・手札の枚数・ターン数・カードのプロパティなどを比較（すべて／どれか）
- **したら（アクション）**：カードを引く／配る・めくる・シャッフル・回収、移動（手札・置き場・マス・ゲーム外）、トラック上を進める／戻す、裏返す、所有者変更、ダイスを振る、変数・カウンター増減、次の手番・もう一度・手番指定・順番反転・フェーズ変更、タイマー開始、メッセージ表示、勝者決定、ゲーム終了

よく使うルールはテンプレートからワンクリックで追加できます。ルールが無くても、テストプレイでは部品を自由に動かして遊べます（サンドボックス）。
無限ループになるルールは自動的に停止します。

### 3. プレイヤー・設定

人数（1〜8人）、プレイヤー名・色、プレイヤー変数（得点・お金など）、共通変数、フェーズ、テーブルのサイズ・色・画像。

### 4. テストプレイ

- 1台の画面を交代で使うホットシート形式。交代時に画面を隠して手札を見せないようにできます
- ドラッグで移動、ダブルクリックで「振る／裏返す／引く」、右クリック（タッチは長押し）でメニュー
- 画面下の手札エリアにドラッグで手札へ、手札から場やエリアへドラッグで出す
- 変数の手動調整、ログ表示、1手ずつ戻す、最初からやり直し、「全員の視点」（デバッグ用）

### 5. 保存

- 編集内容はブラウザ（IndexedDB）に自動保存
- 「書き出し」で `.bgame.json` ファイルに保存、ホーム画面の「ファイルから読み込む」で復元・共有

## サンプル

すごろく／ナンバーレース／トランプ（フリー）／チェス／リバーシ／五目並べ をホーム画面から複製して編集できます。

## 構成

```
src/
  types.ts            ゲーム定義・プレイ状態の型
  model.ts            部品の既定値・ユーティリティ
  catalog.ts          部品パレット（プリセット）
  ruleMeta.ts         ルールエディタの表示名・既定値
  samples.ts          サンプルゲーム
  storage.ts          IndexedDB 保存・ファイル入出力
  engine/engine.ts    ルールエンジン（イベント→条件→アクション）・プレイ操作
  engine/geometry.ts  マス目の計算（正方形・六角・交点・トラック）
  editor/             エディタ画面（パレット・インスペクタ・ルール・設定）
  play/PlayView.tsx   テストプレイ画面
  ui/                 テーブル描画・部品描画・フォーム部品
```
